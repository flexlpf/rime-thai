# rime-thai · แป้นพิมพ์ภาษาไทยสำหรับ Rime (พิมพ์ไทยด้วยอักษรโรมัน / คาราโอเกะ & แป้นพิมพ์เกษมณี)

<p align="center">
  <a href="./README.md">简体中文</a> ·
  <a href="./README.en.md">English</a> ·
  <b>ภาษาไทย</b>
</p>

**`rime-thai`** คือชุดแป้นพิมพ์ภาษาไทยแบบโอเพนซอร์สสำหรับ **[Rime Input Method Engine](https://rime.im/)** (รองรับทั้ง Weasel บน Windows, Squirrel บน macOS, ibus-rime / fcitx5-rime บน Linux และ Trime บน Android) รองรับทั้ง**การพิมพ์ภาษาไทยด้วยอักษรโรมัน / ตัวอักษรภาษาอังกฤษตามเสียงอ่าน (Thai Phonetic / Romanization IME)** และ**ผังแป้นพิมพ์เกษมณีมาตรฐาน (Kedmanee)** ออกแบบโครงสร้างโดยอ้างอิงจาก [rime-cantonese](https://github.com/CanCLID/rime-cantonese) และ [rime-ipa](https://github.com/rime/rime-ipa)

เมื่อติดตั้งแล้วสามารถเลือกเปิดใช้งานผังแป้นพิมพ์ได้ **2 รูปแบบ**:

| รหัสผัง (Schema ID) | ชื่อที่แสดง | ลักษณะการใช้งาน | จุดเด่น |
| :--- | :--- | :--- | :--- |
| **`thai_roman`** | **泰語拼音** (พินอินภาษาไทย / คาราโอเกะ) | พิมพ์ภาษาไทยด้วยอักษรโรมันตามเสียงอ่าน (RTGS / Paiboon) | คลังคำศัพท์ความถี่สูงกว่า **23,800+ คำ**; พิมพ์ได้ทันที**โดยไม่ต้องใส่วรรณยุกต์**, รองรับการย่อเสียงสระสั้น-ยาว, พิมพ์ตัวย่อพยัญชนะต้น, พิมพ์พยัญชนะไทยครบทั้ง 44 ตัว และมีสวิตช์เปิด/ปิดคำใบ้การออกเสียง (`spelling_hints`) |
| **`thai_kedmanee`** | **泰語鍵盤** (แป้นพิมพ์เกษมณี) | พิมพ์สัมผัสตามผังแป้นพิมพ์ภาษาไทยมาตรฐาน | ตรงตามมาตรฐานผลิตภัณฑ์อุตสาหกรรม **มอก. 820-2538 (Kedmanee)** ทุกปุ่ม สลับภาษาภายใน Rime ได้ทันทีโดยไม่ต้องเปลี่ยนภาษาของระบบปฏิบัติการ |

## 1. วิธีการติดตั้ง (Installation)

### วิธีที่ 1: ติดตั้งผ่านหน้าต่างตั้งค่าของ Weasel บน Windows (แนะนำ)
1. คลิกขวาที่ไอคอน Weasel บนแถบงาน (Taskbar) → เลือก **"ตั้งค่าแป้นพิมพ์ (輸入法設定)"**
2. คลิกปุ่ม **"รับผังแป้นพิมพ์เพิ่มเติม... (獲取更多輸入方案…)"** ที่มุมซ้ายล่าง
3. พิมพ์ชื่อคลังโค้ดด้านล่างลงในหน้าต่างคำสั่งแล้วกด Enter:
   ```text
   flexlpf/rime-thai
   ```
4. เมื่อดาวน์โหลดเสร็จสิ้น ให้ติ๊กเลือก **"泰語拼音"** และ/หรือ **"泰語鍵盤"** แล้วกดยืนยันเพื่อประมวลผล (Deploy)

### วิธีที่ 2: ติดตั้งผ่านบรรทัดคำสั่ง `plum` (`rime-install`)
```bash
bash rime-install flexlpf/rime-thai
```

### วิธีที่ 3: คัดลอกไฟล์ด้วยตนเอง (Manual / Git Clone)
คัดลอกไฟล์ `*.yaml` ทั้งหมดไปยังโฟลเดอร์ข้อมูลผู้ใช้ของ Rime (`%APPDATA%\Rime` บน Windows, `~/Library/Rime` บน macOS, `~/.config/ibus/rime` หรือ `~/.local/share/fcitx5/rime` บน Linux) จากนั้นเพิ่มรายการในไฟล์ `default.custom.yaml`:
```yaml
patch:
  schema_list:
    - {schema: thai_roman}      # พิมพ์ภาษาไทยด้วยอักษรโรมัน
    - {schema: thai_kedmanee}   # แป้นพิมพ์เกษมณีมาตรฐาน
```
บันทึกไฟล์แล้วสั่ง **Deploy (重新部署)**

## 2. วิธีการใช้งาน (Usage Guide)

### ผังที่ 1: `thai_roman` (การพิมพ์ภาษาไทยด้วยอักษรโรมัน)

#### ก. การพิมพ์คำศัพท์และวลี (ไม่ต้องใส่วรรณยุกต์)
ระบบรองรับการพิมพ์ตามหลักการถอดอักษรไทยเป็นอักษรโรมันแบบถ่ายเสียงของราชบัณฑิตยสภา (RTGS) และแบบ Paiboon โดยไม่จำเป็นต้องระบุตัวเลขวรรณยุกต์ และรองรับการพิมพ์ตัวย่อพยัญชนะต้น:

| คำภาษาไทย | ความหมาย | พิมพ์แบบไม่ใส่วรรณยุกต์ (แนะนำ) | พิมพ์สระเสียงยาว / รูปแบบอื่น | พิมพ์แบบระบุเลขวรรณยุกต์ (1-5) | พิมพ์ตัวย่อ |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **สวัสดี** | สวัสดี | `sawatdi` | `sawatdii` | `sa2wat2dii1` | `swd` |
| **ขอบคุณ** | ขอบคุณ | `khopkhun` | `khorpkhun` / `khoopkhun` | `khoop2khun1` | `kk` / `khkh` |
| **ไม่เป็นไร** | ไม่เป็นไร | `maipenrai` | `maibpenrai` | `mai3pen1rai1` | `mpr` |
| **ภาษาไทย** | ภาษาไทย | `phasathai` | `phaasaathai` | `phaa1saa5thai1` | `pst` / `phsth` |
| **กรุงเทพฯ** | กรุงเทพฯ | `krungthep` | `grungtheep` | `krung1theep3` | `kt` / `krth` |
| **ใบเสนอราคา** | ใบเสนอราคา | `baisanoerakha` | `baisanerrakha` | `bai1sa2noee5raa1khaa1` | `bsnrk` |

#### ข. การกรองคำพ้องเสียงด้วยเลขวรรณยุกต์ (1–5 หรือปุ่มลัด)
หากต้องการเจาะจงเสียงวรรณยุกต์ สามารถพิมพ์ตัวเลข `1`–`5` (หรือปุ่มลัด `v / x / q / f / r`) ท้ายพยางค์:

| เลขวรรณยุกต์ | ปุ่มลัด | ชื่อเสียงวรรณยุกต์ | ระดับเสียง (IPA) | ตัวอย่างการพิมพ์ |
| :---: | :---: | :--- | :---: | :--- |
| **`1`** | `v` | เสียงสามัญ (Mid) | `˧` (33) | `maa1` → มา |
| **`2`** | `x` | เสียงเอก (Low) | `˨˩` (21) | `mai2` → ใหม่ |
| **`3`** | `q` | เสียงโท (Falling) | `˥˩` (51) | `mai3` → ไม่ / ม่าย |
| **`4`** | `f` | เสียงตรี (High) | `˦˥` (45) | `maa4` → ม้า, `naam4` → น้ำ |
| **`5`** | `r` | เสียงจัตวา (Rising) | `˩˩˦` (114) | `maa5` → หมา, `mai5` → ไหม |

#### ค. การพิมพ์พยัญชนะเดี่ยว 44 ตัว สระ วรรณยุกต์ และตัวเลขไทย
- **พยัญชนะไทยทั้ง 44 ตัว (พิมพ์ได้ 2 วิธี)**:
  1. **พิมพ์ตามเสียงพยัญชนะต้น**: เช่น `k` (`ก`), `kh` (`ค ข ฆ ฃ ฅ`), `ch` (`จ ช ฉ ฌ`), `s` (`ส ซ ศ ษ`), `th` (`ท ถ ธ ฐ ฑ ฒ`)
  2. **พิมพ์ตามชื่อตัวอักษร (ได้ตัวอักษรนั้นทันที)**:
     - อักษรกลาง: `kokai` (`ก`), `chochan` (`จ`), `dochada` (`ฎ`), `topatak` (`ฏ`), `dodek` (`ด`), `totao` (`ต`), `bobaimai` (`บ`), `popla` (`ป`), `oang` (`อ`)
     - อักษรสูง: `khokhai` (`ข`), `khokhuat` (`ฃ`), `choching` (`ฉ`), `thothan` (`ฐ`), `thothung` (`ถ`), `phophueng` (`ผ`), `fofa` (`ฝ`), `sosala` (`ศ`), `soruesi` (`ษ`), `sosuea` (`ส`), `hohip` (`ห`)
     - อักษรต่ำ: `khokhwai` (`ค`), `khokhon` (`ฅ`), `khorakhang` (`ฆ`), `ngongu` (`ง`), `chochang` (`ช`), `soso` (`ซ`), `chochoe` (`ฌ`), `yoying` (`ญ`), `montho` (`ฑ`), `thophuthao` (`ฒ`), `nonen` (`ณ`), `thothahan` (`ท`), `thothong` (`ธ`), `nonu` (`น`), `phophan` (`พ`), `fofan` (`ฟ`), `phosamphao` (`ภ`), `moma` (`ม`), `yoyak` (`ย`), `roruea` (`ร`), `loling` (`ล`), `wowaen` (`ว`), `lochula` (`ฬ`), `honokhuk` (`ฮ`)
- **รูปสระและเครื่องหมายวรรณยุกต์**:
  - `saraa` (`ะ`), `saraaa` / `aa` (`า`), `maihanakat` (`ั`), `saraam` (`ำ`), `sarai` (`ิ`), `saraii` (`ี`), `saraue` (`ึ`), `sarauee` (`ื`), `sarau` (`ุ`), `sarauu` (`ู`), `sarae` (`เ`), `saraae` (`แ`), `sarao` (`โ`), `maimuan` (`ใ`), `maimalai` (`ไ`), `rue` (`ฤ`), `lue` (`ฦ`)
  - `maiek` / `tone2` (`่`), `maitho` / `tone3` (`้`), `maitri` / `tone4` (`๊`), `maichattawa` / `tone5` (`๋`), `maitaikhu` (`็`), `karan` (`์`), `maiyamok` (`ๆ`), `paiyannoi` (`ฯ`), `paiyanyai` (`ฯลฯ`), `baht` หรือปุ่ม `\` (`฿`)
- **ตัวเลขไทย (`๐`–`๙`)**:
  - `sun` (`๐`), `nueng` (`๑`), `song` (`๒`), `sam` (`๓`), `si` (`๔`), `ha` (`๕`), `hok` (`๖`), `chet` (`๗`), `paet` (`๘`), `kao` (`๙`)

#### ง. สวิตช์เปิด/ปิดคำใบ้การออกเสียง (`spelling_hints`)
ค่าเริ่มต้นจะแสดงคำอ่านอักษรโรมันกำกับท้ายตัวเลือกคำศัพท์ (เช่น `สวัสดี [sa2 wat2 dii1]`) หากต้องการปิด สามารถเปลี่ยนค่า `spelling_hints: 8` เป็น `0` ในไฟล์ `thai_roman.schema.yaml` หรือสร้างไฟล์ `thai_roman.custom.yaml`:
```yaml
patch:
  translator/spelling_hints: 0
```
